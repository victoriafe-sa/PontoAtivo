Resposta:  
A idade mínima para participar do projeto Semear não foi confirmada com base nas evidências fornecidas.

Limitações:  
A informação disponível refere-se aos Centros Olímpicos e Paralímpicos (COPs) do DF, que oferecem modalidades para pessoas a partir de 04 (quatro) anos de idade. No entanto, o projeto Semear não foi mencionado ou relacionado a essa evidência. Portanto, não é possível confirmar a idade mínima para o projeto Semear com base nas informações fornecidas.
