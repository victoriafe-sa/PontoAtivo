# Documentos-fonte em texto (25)

Texto copiável de 25 documentos-fonte sobre espaços de prática de atividade física no Distrito Federal
(PECs, parques, estádios, centros olímpicos, clubes) e regras de uso desses espaços.

- **Lista completa** (título, órgão, link, tema, data de coleta, ressalvas): [`LISTA_FONTES.md`](LISTA_FONTES.md)
  e [`lista_fontes.csv`](lista_fontes.csv).
- **Arquivos:** `F###_titulo.txt`. O `F###` é o ID da base de conhecimento. Cada `.txt` começa com um
  cabeçalho (título, órgão, link, tema, abrangência, data de coleta, situação da revisão e ressalvas) e,
  depois da linha `====`, traz o texto da página.
- `F003_original.pdf` é o PDF original do Manual de Uso dos Centros Olímpicos e Paralímpicos (as demais fontes
  são páginas web, convertidas para texto).

## Como foram obtidos

Páginas oficiais coletadas em **05/11/2026** (sites `*.df.gov.br`, mais 3 páginas do Sesc-DF), com o texto
extraído e limpo automaticamente (menus, scripts e rótulos de interface removidos). O texto é o que estava
publicado na data de coleta; as páginas podem ter mudado.

## Limitações (leia antes de usar)

- **Revisão assistida por software/IA, sem leitura integral por uma pessoa.** Confira no link antes de usar como
  informação oficial.
- **F028 (COPs):** a tabela de modalidades não é texto no site e **não aparece** aqui; os endereços dos 12 COPs sim.
- **F006, F007, F008 (Sesc-DF):** site oficial da entidade, que **não é governamental**.
- **F013:** PEC dentro de uma instituição de acolhimento; o acesso pode ser restrito.
- **Notícias de obra ou projeto** (por exemplo F014, F076, F077): não confirmam espaço entregue nem em funcionamento.
- **F003, F063, F064, F075:** normas ou regras de uso; conferir vigência. O F003 é de 2022.
- Nenhuma informação de acessibilidade foi auditada em campo.
- Os textos citam nomes e telefones **institucionais** (direção de unidades, contatos) que constam das páginas
  oficiais públicas.
